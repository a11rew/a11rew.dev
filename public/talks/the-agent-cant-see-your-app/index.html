The actual lesson

The agent had the code
the whole time.

Which can look like everything. It isn't. It still had to be given the context — and the goal.
"An idle screen commits zero times."
Go into the loop: here's your context, here's the exit goal. Write it down once, and the agent closes the loop without you.

Worth keeping

metro-mcp the inspector

Fiber tree, props, testIDs, console, network, profiling. All over CDP.

claude mcp add metro-mcp -- npx -y metro-mcp
mobile-mcp the driver

Taps, swipes, typing, screenshots. iOS and Android, simulator or real device.

github.com/mobile-next/mobile-mcp
React DevTools Profiler

Tick "record why each component rendered" first. Export the JSON, let the agent parse it.

npx react-devtools
context7

Library docs at the version you actually depend on. Kills the confidently-called, renamed-two-versions-ago function.

github.com/upstash/context7
Maestro

UI test runner. metro-mcp can record a real interaction and generate a Maestro flow with real selectors.

maestro.dev
Hermes allows one CDP connection

Pressing j in Metro, or opening the dev-menu debugger, steals it and silently drops your MCP. metro-mcp's proxy multiplexes around it.

chrome-devtools-mcp cannot work

Puppeteer-based, needs CDP domains Hermes does not implement. Architectural, not environmental.
