I gave this talk at Claude Code Accra in August 2026.

Claude Code can't curl your iOS app or read its DOM. It makes a change, and then it has to ask you whether the change worked. The talk is about closing that gap: instrumenting the app so the agent can see what it just did, and giving it a definition of "working" it can check itself against.
